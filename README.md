# conv
Simple command line tool for conversions between units.

### Usage
`conv <number> <fromUnit> <toUnit>`

### Supported Units
| Unit | Commands |
| ---- | -------- |
| Fahrenheit   | ["fahrenheit", "f"] |
| Celcius      | ["celcius", "c"] |
| Kelvin       | ["kelvin", "k"] |
| Mile         | ["mile", "mi"] |
| Meter        | ["meter", "metre", "m"] |
| Centimeter   | ["centimeter", "cm"] |
| Kilometer    | ["kilometer", "km"] |
| Inch         | ["inch", "in"] |
| Foot         | ["foot", "feet", "ft"] |
| Yard         | ["yard", "yd"] |
| Fathom       | ["fathom"] |
| NauticalMile | ["nauticalmile", "nm", "nmi"] |
| Second       | ["second", "s"] |
| Minute       | ["minute", "min"] |
| Hour         | ["hour", "hr"] |
| Day          | ["day"] |
| Week         | ["week", "wk"] |
| Month        | ["month", "mo"] |
| Year         | ["year", "yr"] |
| Kilogram     | ["kilogram", "kilo", "kg"] |
| Gram         | ["gram", "g"] |
| Ounce        | ["ounce", "oz"] |
| Pound        | ["pound", "lb"] |
| Liter        | ["liter", "litre", "l"] |
| FluidOunce   | ["fluidounce", "floz"] |
| Cup          | ["cup"] |
| Pint         | ["pint"] |
| Quart        | ["quart"] |
| Gallon       | ["gallon", "gal", "gl"] |

### help
`conv --help`
